MiniSec 关卡清单

Level List

靶场默认只监听 127.0.0.1，只在你自己的机器上运行。克隆仓库后三条命令即可开始：python init_db.py → python app.py → 浏览器打开 http://127.0.0.1:5001（演示账号 admin / 123456）。

SQL 注入 · 3 关

  • Level 1 基础查询注入　payload admin' OR '1'='1' --　判定：一次查询返回的行数大于 1
  • Level 2 登录绕过　payload 用户名 admin' --　判定：以 admin 进入系统，且提交的账号密码不是一组合法凭据
  • Level 3 UNION 查询　payload ' UNION SELECT id, title, content, 'x' FROM secret_notes --　判定：结果里出现内部表的 flag

XSS · 2 关

  • Level 1 反射型　payload <script>alert(1)</script>　判定：回显 HTML 里存在可执行结构（这一关故意不做过滤）
  • Level 2 存储型　payload <img src=x onerror=alert(1)>　判定：数据库里存在可执行留言（弱黑名单只挡 script 标签）

文件上传

  • 校验只做后缀黑名单，且文件被存进 web 可以直接访问的目录　判定：文件保存成功，且它的文件头不是图片

SSRF 服务端请求伪造

  • 服务端替你请求任意 URL　判定：目标是内网/环回地址，且响应里含内部标记

命令注入

  • 网络诊断工具，输入被拼进系统命令　判定：输出里出现沙箱文件的 flag（Windows 用 & 分隔，Unix 用 ;）

越权访问 IDOR

  • 身份不变、把编号改一个数字就读到别人的笔记　判定：读到的数据归属与当前身份不一致

CSRF 跨站请求伪造

  • 模拟攻击者页面自动提交表单，借你已登录的身份发请求　判定：数据库里的邮箱被改成攻击者地址

Every level includes 3 levels of hints, a "why it worked / why it didn't" analysis, and a vulnerable-vs-fixed code comparison.
