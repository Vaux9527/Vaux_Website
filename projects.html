MiniSec

网络安全漏洞实验平台

Web Vulnerability Learning Platform

MiniSec 是一个面向网络安全学习者的 Web 漏洞实验平台。它通过模拟真实的漏洞环境，把抽象的漏洞原理变成可以亲手触发、观察与修复的完整过程——从 SQL 注入、XSS 等典型场景出发，帮助学习者在「看得见」的攻防中真正理解 Web 安全，而不仅仅是背诵概念。

平台采用 Flask + SQLite 的轻量技术栈，本地即可快速搭建，也便于按需扩展新的实验场景；既可以作为自学与备赛的练习环境，也可以用于团队内部的技术分享演示。

平台特点

Highlights

  • 内置 SQL 注入、XSS 等典型 Web 漏洞场景，还原真实的触发与利用过程
  • 关注「漏洞成因 → 利用方式 → 修复方案」的完整学习闭环
  • Flask + SQLite 轻量实现，部署简单、易于二次开发
  • 与静态教程互补，提供可动手操作、可反复重置的实验环境

MISC Hunter

CTF MISC 自动化分析工具

Automated CTF MISC Analysis Engine

MISC Hunter 是一个模块化的 CTF MISC 分析引擎：输入一个可疑文件，引擎会自动识别文件类型、执行常见分析、发现异常特征，再调用对应插件提取隐藏数据，并把每个新产物重新送入分析队列继续递归，直到没有新的发现，最终输出日志、报告与提取链。

它的设计哲学很朴素——「机械自动化，推理留人类」：找到 flag 就直接报告；找不到就把文件、字符串与解码候选清晰地呈现出来；分析不出来的则明确列入「待人工分析」清单，绝不悄悄消失。从 v1.0 到 v3.0，工具覆盖面不断加深，核心依然保持纯 Python 实现、零强制第三方依赖，Kali Linux 与 Windows 均可运行。

2026 年 9 月 7 日，v4.0 发布——搭载 DeepSeek 的 AI 辅助层（--ask / --rank / --agent 三种只读模式）随之落地，MISC Hunter 四代版本全部完成并正式结项：从 v1.0 一条能跑的流水线，成长为「确定性分析 + 人机接力 + AI 建议」的完整 MISC 分析体系。

核心能力

Capabilities

  • 全流程自动化：类型识别 → 隐写检测 → 数据提取 → 递归分析，结果汇总为报告与提取链
  • 插件自动发现：一个插件只解决一个问题，按 priority 自动编排，扩展插件无需改动主程序
  • 异常隔离与降级：单个插件崩溃不影响整体分析，外部工具缺失时自动提示并跳过
  • 人机接力：自动解密失败时通过 DECRYPT_NEEDED 把线索交给人类，支持目录批量分析与递归护栏
  • 密钥解密框架：XOR → Serpent → AES/DES/3DES 组合尝试，命中即报告完整解密路径
  • 候选不丢弃：无法唯一判定的爆破候选全部落盘，交由字符串匹配与人工最终裁决
  • AI 只读辅助（v4.0）：--ask 解释 / --rank 候选裁决 / --agent 研究建议，AI 只提供建议、从不参与最终裁决
