# 项目展示 | Projects

## MiniSec

### 网络安全漏洞实验平台

### Web Vulnerability Learning Platform


MiniSec 是一个面向网络安全学习者的 Web 漏洞实验平台。

通过模拟真实漏洞环境，帮助学习者理解 Web 安全漏洞原理，
包括 SQL Injection、XSS 等常见漏洞。

MiniSec is a Web vulnerability learning platform designed
for cybersecurity learners.

It provides simulated vulnerable environments to help understand
common Web security vulnerabilities such as SQL Injection and XSS.


Technology:

- Flask
- SQLite
- HTML/CSS
- Web Security


Repository:

https://github.com/Vaux9527/Vaux-Security-Lab

## MISC Hunter

### 自动化 CTF MISC 图片分析工具

### Automated CTF MISC Image Analysis Tool


MISC Hunter 是一个面向 CTF MISC 方向的自动化分析工具。

目标是通过自动化流程辅助分析图片类题目，
包括文件结构检测、隐藏数据提取、图片修复、
隐写分析以及详细过程记录。

MISC Hunter is an automated analysis tool
for CTF MISC challenges.

It aims to assist image-based challenge solving through automated
analysis workflows, including file inspection, hidden data extraction,
image recovery, steganography analysis and detailed reports.


Technology:

- Python
- Image Processing
- File Analysis
- Steganography


Repository:

https://github.com/Vaux9527/MISC-Hunter-v1.0
